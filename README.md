# Smart Expense Tracker

A simple expense tracking web application built with HTML, CSS, and JavaScript. It allows users to manage expenses, view spending summaries, and organize their records through search and sorting.

## Live Demo

[Open Smart Expense Tracker](https://sagittarius6996.github.io/smart-expense-tracker/)

## Features

- **Expense Management:** Add, view, edit, and delete expenses.
- **Dashboard:** View total spending, monthly spending, and spending by category.
- **Search:** Find expenses by title, category, or date.
- **Sorting:** Sort expenses by amount or date in different orders.
- **Data Persistence:** Store expense records in the browser using localStorage, so they remain available after refreshing the page.
- **Responsive Interface:** A dark dashboard layout designed to work across different screen sizes.

## Built With

- HTML5
- CSS3
- JavaScript
- Browser localStorage API

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sagittarius6996/smart-expense-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd smart-expense-tracker
   ```

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.
